Entry for the [make.fun](https://make.fun) bounty **Monday, Reviewed in One Line**
([bounty page](https://make.fun/bounty/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1)): one funny
one-line review of the entrant's own Monday, under 200 characters. Free entry.

## The line

> My Monday inbox had 47 unread emails: 46 were meetings about the emails, and one was IT asking why I opened them all.

(117 characters, one line, no trailing newline.)

## How to run

Requires Node 22+ (stdlib only, no dependencies):

```sh
node main.ts
```

This writes the line to `/output/entry.txt`. For local testing, override
the output directory:

```sh
OUTPUT_DIR=/tmp/monday-reviewed-out node main.ts
```

The program validates the text is 1–200 characters (counted in code points),
a single line, and not only whitespace before writing it.
